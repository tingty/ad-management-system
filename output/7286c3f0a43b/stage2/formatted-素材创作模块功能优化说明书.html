1. 概述

1.1 背景与定位

素材创作模块是面向"广告投放精品化"的独立生产能力。它服务于海外移动互联网效果广告团队，将单一落地页（或产品 brief）综合分析后，分别产出可直接投放的推广图片与推广视频。与"创作工作台"的区别在于：创作工作台偏向通用 / 批量生产，而素材创作模块强调风格多样性、精品质感与一次性交付。

1.2 优化目标

  • 落地页分析从"通用报告"升级为九要素结构化总结（行业、类型、品类、满足需求、解决方案、商业模式、优势对比、差异化特色、一段话目的总结），并延伸输出行业 / 竞品 / 市场需求 / 差异化方案 / 特色优势，以及推荐媒体与人群。
  • 媒体平台设置从"多选平台"改为单次单选平台，并把该平台支持的素材规则（类型 / 尺寸 / 规格）拆为可配置选项：同类单选、不同类可多选。
  • 图片与视频两个子模块均提供极丰富的创意方向、创意内容风格与配色方案，以简单选择 + 弹窗查阅详情的方式降低使用门槛。
  • 视频创作在图片能力基础上，额外支持"借鉴市场总结再创作"，利用分析产出的行业 / 竞品 / 市场信息二次深化。
  • 最终产物为可直接投放的图片 / 视频素材，不在平台内做二次编辑或调试。
  • 交互上贯彻简洁设计、向导分步（单步聚焦）、上下布局、展开收缩、组件统一五项原则（详见第 2 章）。

1.3 范围与边界

1.4 与"创作工作台"的关系

素材创作模块复用创作工作台的同一套落地页分析引擎（/api/report）与品牌档案（Brand Profile）。区别在于：

  • 创作工作台面向"多平台批量"，素材创作面向"单平台精品"；
  • 素材创作额外叠加"创意方向库 / 内容风格库 / 配色库"三层可选项；
  • 素材创作的分析视图（ReportView）与创作工作台逐字一致，确保同一事实源；
  • 素材创作在交互上以向导 + 单步聚焦呈现，区别于创作工作台的平铺式布局。

1.5 角色与权限（保持不变）

权限模型不改造。沿用既有规则：素材创作对编辑（editor）及以上角色可见可操作；只读（viewer）、分析师等角色不可见该二级菜单；管理员（admin）拥有全部能力。系统其他模块的权限判定不变。

2. 界面设计与交互规范（核心设计原则）

本章为本说明书的交互基线，所有功能模块（第 3–6 章）均须遵循。设计目标：简洁、清晰、专注、纵向、可折叠、风格统一。

2.1 简洁设计方案总览

  • 少即是多：每个页面只承载"当前这一件事"，不堆砌无关信息；次级信息默认折叠。
  • 流程清晰：以"步骤条 + 单步内容"的向导模式组织全流程，用户始终知道"现在在哪一步、下一步去哪"。
  • 信息分层：强制信息优先级——标题（是什么）→ 一句话说明（为什么）→ 操作区（怎么做）→ 操作按钮（确认），自上而下。
  • 降低认知负荷：选项以"卡片 / 标签简单展示 + 弹窗看详情"为主，避免长表单；风格 / 配色等密集选项以网格 + 折叠呈现。

2.2 向导式分步流程（每步专注当前操作）

整页采用"步骤条 + 单步内容"模式，将素材创作拆为四个阶段，每一步只展示与当前阶段相关的操作模块，其余步骤收起或置灰：

步骤阶段名当前专注的操作模块完成后解锁
①落地页分析URL / 正文输入 + 分析结果（九要素 / 延伸 / 推荐）步骤 ②
②媒体平台设置平台单选 + 素材规则三分类（类型 / 尺寸 / 规格）步骤 ③
③创意素材设置"图片 / 视频"Tab 切换，每个 Tab 内纵向排布"创意方向 → 内容风格 → 配色"步骤 ④
④生成与交付生成进度 + 产物预览 / 下载—（终态）
  • 单步聚焦：未到达的步骤显示为"未完成"灰态且不可交互；仅当前步内容可操作。上一步的结果以"摘要条"折叠展示，点击展开回顾，不挤占当前步空间。
  • 步骤推进：通过底部统一风格的"上一步 / 下一步 / 生成"按钮推进；未满足当前步必填项时"下一步"禁用并提示。
  • 状态保持：步骤间数据自动暂存，返回上一步不丢失已填内容。

2.3 上下布局与信息纵向排布

  • 页面默认单列纵向，不使用左右分栏，阅读顺序严格自上而下，符合自然阅读动线。
  • 每个功能块统一结构（纵向堆叠）：
    1. 区块标题（如"创意方向"）
    2. 一句话说明（可选，解释用途）
    3. 输入 / 选项区（如输入框、选项网格）
    4. 区块内操作（如"添加"）
  • 图片与视频子模块内的"创意方向 / 内容风格 / 配色"三组，在各自 Tab 内以三段式纵向卡片排列（而非并排三列），保证窄屏 / 移动端一致体验。
  • 说明文字置于对应控件正上方，避免用户跨栏对照；相关项就近摆放。

2.4 展开 / 收缩（长内容折叠）

针对内容主体过长的区块，采用就地展开 / 收缩，避免整页无限拉长：

  • 默认折叠：九要素总结（9 项）、延伸输出、创意方向库（20 项）、内容风格库（26 项）、配色库（16 项）等默认折叠，仅显示标题与"已选 N 项 / 共 M 项"摘要。
  • 交互：点击区块标题或右侧"展开 / 收起"箭头，在当前位置就地展开 / 折叠；展开内容可独立滚动，不影响整页其他区块。
  • 智能展开：用户刚进入某区块编辑（如点击"创意方向"）时自动展开该区块，其余保持折叠，维持专注。
  • 折叠态摘要：折叠时显示已选摘要（如"创意方向：国潮、卖点直击"），便于快速回顾而无需展开。

2.5 统一组件风格（输入框 / 选项 / 按钮）

  • 全模块所有输入框、单选 / 多选选项、按钮使用同一套设计令牌（Design Token），禁止混用旧版不同圆角 / 边框 / 字号的控件。
  • 主色统一取自系统主题色（与"品牌色 / 素材配色"分离，避免与素材配色混淆，也避免切换素材配色时按钮色跟着变）。
  • 组件状态一致：默认 / 聚焦（输入框）/ 选中（选项）/ 悬停 / 禁用 / 加载，每种状态在所有同类组件中表现相同。

2.6 统一组件规格表

4. 功能说明

以下三个模块对应向导的 ① ② ③ 步，均遵循第 2 章交互规范：单步聚焦、上下布局、可折叠、组件统一。

4.1 模块 A：落地页综合分析（统一分析层 · 向导①）

模块 A 是图片与视频两个子模块的共同前置，只需分析一次，结果被两个子模块共享，是"风格一致性"的事实来源。在向导①中以单步聚焦呈现：仅展示"输入区 + 分析结果"。

A1 落地页抓取与解析

  • 输入方式一：粘贴产品落地页 URL，系统抓取整页正文、标题、H1/H2、CTA、图片与视频信号。
  • 输入方式二：当链接无法抓取（JS 渲染失败、内网测试页、仅有一份产品文档）时，提供"正文 / 产品说明"粘贴框，直接以文本分析。
  • 解析产出：结构化页面字段（标题、描述、主张、信号指标、人群线索、语言），作为后续总结与创意规划的事实基础。

A2 结构化总结（九要素）

系统基于解析结果，产出以下九项结构化总结，每一项为独立可展示字段。默认以折叠区块展示，展开后逐项纵向排列：

序号要素说明
1行业产品所属一级行业（如 工具 / 电商 / 游戏 / 金融 / 健康）
2类型业务类型（如 SaaS / 实物电商 / 手游 / 网服）
3品类细分品类（如 拍照修图 App / 女装 DTC / 三消手游）
4满足的市场或用户需求产品解决的具体痛点与被满足的需求
5解决方案产品如何解决问题（核心机制 / 能力）
6商业模式变现方式（IAA / IAP / 订阅 / 电商交易 / 引流）
7优势对比与同类方案相比的显性优势（性能 / 价格 / 体验）
8差异化特色不可替代或独有卖点（技术 / 内容 / 渠道）
9一段话总结落地页的主要目的用 1–2 句话概括该落地页的核心推广目标（如拉新 / 转化 / 品牌）

A3 延伸输出

在九要素之上，进一步归纳输出以下五类延展信息，供创意方向与视频"再创作"使用（折叠区块，可展开）：

  • 行业：行业趋势、监管与典型打法。
  • 竞品：主要竞品、其主张与可乘之机。
  • 市场需求：目标市场的规模、增速与未被满足的需求。
  • 差异化方案：基于差异化特色可落地的创意切入点。
  • 特色优势：可对外传播的优势资产（数据 / 背书 / 案例）。

A4 媒体与人群推荐

结合九要素与平台特征，给出推荐项（折叠区块，可展开）：

  • 推荐市场推广媒体：适合本品类的媒介类型（如 信息流 / 激励视频 / 搜索 / 联盟）。
  • 推荐媒介平台：具体平台清单（如 Facebook、Instagram、TikTok、Google、YouTube、Unity、AppLovin、微信、抖音、小红书等）。
  • 市场人群对象：核心人群画像（年龄 / 兴趣 / 地域 / 行为），作为投放与创意口吻的依据。

4.2 模块 B：媒体平台与创意素材设置（向导② ③）

B1 媒体平台单选 + 平台素材规则（向导②）

  • 单次仅可选一个媒体平台。选定后，系统加载该平台的素材规则，呈为三类可配置项（纵向排列，每类一个折叠区块）：
    • 素材类型（如 单图 / 视频 / 轮播 / 动态广告）：单选。
    • 素材尺寸（如 1080×1080、1080×1920、1200×628、1080×1350）：单选。
    • 素材规格（如 文件格式、时长上限、文件大小、帧率）：单选。
  • 选择规则：同类单选，不同类可以一次多选。例如可同时选"单图 + 视频"两种类型，并各自选一个尺寸与一份规格；但"素材类型"内部只能选一个，"素材尺寸"内部只能选一个。
  • 规则来源：平台规则库（platform_spec 扩展），可按平台维护，随平台迭代扩充。

B2 创意图片子模块（向导③ · 图片 Tab）

  • 在 B1 规则约束下输出图片（多尺寸按所选规则生成）。
  • 进入该 Tab 后，纵向排布三个可折叠区块（单步聚焦，互不干扰）：
    1. 创意方向：以卡片 / 标签简单展示，点击弹窗查阅完整方向与描述；可多选（建议 1–4 个）。
    2. 创意内容：选择内容风格（纯色背景图、人物风格、动漫风格、风景风格、国画风格、油画风格等，详见第 6.3 节）。
    3. 配色：选择配色类型（多彩、简洁、深色、浅色、纯色等，详见第 6.4 节）。
  • 产出为可直接投放的图片素材（含文案与关键词）。

B3 创意视频子模块（向导③ · 视频 Tab）

  • 在 B1 规则约束下输出视频（含关键帧、分镜脚本，支持合成完整 MP4）。
  • 设置项与图片一致，同样以纵向三段式可折叠区块呈现：创意方向 + 创意内容风格 + 配色。
  • 借鉴市场总结再创作：视频子模块额外读取 A3 延伸输出（行业 / 竞品 / 市场需求 / 差异化方案 / 特色优势），在分镜、钩子、卖点编排上做二次深化，使视频更贴合市场真实语境。

4.3 模块 C：生成与交付（向导④）

  • 图片与视频各一个独立"生成"动作，分别产出，互不影响（对应底部"生成"按钮，统一风格）。
  • 产物为直接投放级：图片即成品图，视频即合成成片（无声或带字幕），配套文案与关键词。
  • 提供 ZIP 批量下载与单文件预览 / 下载，平台内不做二次精修。

5.4 创意方向库

创意方向是一套"洞察 + 钩子 + 版式倾向"的创意母题。列表在 6.2 节完整给出；交互上以标签简单展示，点击弹窗显示：方向名、适用子模块、核心洞察、推荐钩子、版式倾向、禁忌。用户勾选后将作用于图片 / 视频的生成提示词。弹窗采用第 2.6 节统一弹窗样式。

5.5 创意内容风格库（图片 + 视频通用）

风格决定画面的视觉基底。完整列表见 6.3 节，每项标注"适用：图片 / 视频 / 通用"。视频向风格（如赛博朋克、蒸汽波、霓虹光影、故障艺术）会同时影响分镜画面与转场。

5.6 配色方案库

配色决定整体色板与品牌色的融合方式。完整列表见 6.4 节。默认选项为"品牌同色系"（跟随 A1 解析出的品牌色衍生），其余为风格化配色。

5.7 视频"借鉴市场总结再创作"

  • 触发：进入视频子模块且已完成 A3 延伸输出。
  • 行为：将"竞品 / 市场需求 / 差异化方案"映射为视频分镜的"钩子—痛点—方案—证明—行动"五段编排；在分镜脚本的 note / text / vo 字段注入市场语境。
  • 产出：视频关键帧与分镜脚本更贴合真实市场，而非通用模板。

5.8 风格一致性保障机制

  • 图片与视频共享同一 framework_id、品牌色、产品图与所选创意方向。
  • 创意方向 / 内容风格 / 配色三者在两个子模块间选项完全一致，用户为图片选"国画水墨 + 莫兰迪"，为视频选同项即可保持视觉同源。
  • 顶部"风格一致性"横幅提示用户两模块共用同一分析 / 品牌 / 方向（可收起，见 2.7）。

8. 状态流转与边界

  • 分析前：模块 B/C（向导②③）禁用；分析完成后解锁。
  • 媒体平台未选：B1 规则不可配置，生成禁用。
  • 未选创意方向：生成禁用（至少 1 个方向）。
  • 平台不支持视频广告位：视频子模块仅产出关键帧 + 分镜，提示"未合成完整视频"。
  • 权限：非编辑角色不展示"素材创作"入口。
  • 向导状态：未满足当前步必填项时"下一步"禁用；返回上一步保留已填数据。
