一、这张图到底在表达什么

一句话概念：它不卖功能，卖「改变」。把空房间变成梦想客厅的落差本身当作证据——用户先看到结果，再被告诉「这个结果用我们的工具就能做到」。

这条广告的心理链条是标准的效果广告结构，六层缺一不可：

  1. 痛点识别：Before 面板是一个空荡、冷调、没有生气的房间——用户立刻认出「这是我家/我空间的现状」。
  2. 渴望激发：After 面板是暖光、绿植、精致陈设的理想客厅，主标题把渴望命名为 Dream Space，并用黄色高亮加下划线锁定视线。
  3. 可信证据：斜切分割 + 黄色箭头把 Before 与 After 绑成一条因果线；中间的「落差」就是产品价值的视觉证明，不需要一句解释。
  4. 能力归因：左下角笔记本里的 2D / 3D 界面，把「这个漂亮结果」归因到软件能力，而不是请了设计师——这是从「心动」到「可信」的关键一跳。
  5. 决策降本：三个图标 + 短句（规划与设计 / 实时 3D / 高清渲染）把复杂产品压缩成三个可记住的理由。
  6. 行动收口：黄色涂鸦标语 + 胶囊按钮 Get Started Free →，用「免费」消除最后一步风险。
可迁移的本质：「一个可视觉化的改变 + 一张证明能做到它的产品界面 + 三个理由 + 一个低风险行动」。任何有「前后状态差异」的产品都能套用：健身（体态）、教育（能力）、护肤（肤质）、修图（画面）、装修（空间）、汽车美容（车况）……

三、变量字典（怎么把模板套到别的产品）

模板能否复用，取决于变量填得是否具体。BEFORE_STATE / AFTER_STATE 必须能被「一眼看出差别」，否则视觉锤失效。

无产品 UI 时，用「产品瓶身 + 使用前后对照卡」替代第三层，强调色用 rose gold。

迁移成败的三个检查点

① Before / After 是否同场景、同机位？否则对比感断裂。

② 「改变后」是否一眼可辨且令人向往？模糊的差异等于没说。

③ UI / 产品证据是否真的能解释这个结果？证据与承诺错位会被识破。

五、落地到创意工作台的建议

与现有能力对齐：本模板可直接作为「图片创意规划」的一条固定路线沉淀，配合 V4.96 的统一提示词规则使用。
  • 文字走叠加，不进画面：优先用 2.2 零文字版出背景；品牌名 / 标题 / 卖点 / CTA 用播放层或设计工具叠加，避免错拼，也方便一图多文案复用。
  • 品牌名取黄金词典：若 Vand 在图上出现品牌字样，只从已确认的品牌词典取值，禁止用户自由输入直接绘制。
  • 数字与承诺过 D0 证据门：卖点里的数字（如「28 天见效」「15 分钟」）必须能在产品分析证据里定位，否则拦截，避免虚假承诺。
  • 绑定素材标准库：出图尺寸按所选媒体平台（Meta / Google / TikTok …）的标准库目标自动适配，比例与像素随平台走。
  • 参考图若用于本模板：按 V4.97，参考图只学习配色 / 质感，不把原图贴进画面——正好适合把「某品牌广告的调性」迁移到新产品。
参数建议：尺寸 1:1（1080×1080）为主，可派生 4:5、9:16；每张图固定随机种子便于同系列复现；每变量组合出 2–4 张择优；强调色全图只用一种，避免视觉噪音。
